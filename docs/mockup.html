Ternary Operator

Fill in the blank — use the ternary operator to set $label to "adult" if $age is 18 or over, otherwise "minor".

$age = 20; $label = ______;
💡 Learning Tips

Ternary Syntax

condition ? value_if_true : value_if_false — a compact if/else in one line.

Common Mistake

Don't nest ternaries — PHP 8 deprecated them. Use if/else for complex logic.

Quick Reference

$x = $a > $b ? 'yes' : 'no';
// same as:
if ($a > $b) $x = 'yes';
else $x = 'no';

Type Juggling

Write PHP code that creates a variable $result containing the integer sum of "5" and 3, then echo it.

$result = "5" + 3; echo $result; // cursor here▌
Output (php-wasm):
8
💡 Learning Tips

Type Juggling

PHP automatically converts types. A string like "5" plus an int 3 gives integer 8.

Common Mistake

Concatenation uses the dot (.) operator, not +. "5" . 3 gives "53", not 8.

Quick Reference

"5" + 3 → 8 (int)
"5" . 3 → "53" (string)
intval("5") → 5
